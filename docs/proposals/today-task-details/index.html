Today: task details without leaving Today

Clicking a task title on Today opens its details in a side panel (a bottom sheet on phones). Status, priority and due date change in place, the checklist ticks off, and Focus / Done / Skip are one click away. "Open in project" goes to the full task when you need more. Clicking the timer ring opens Focus.

Swipe down or tap outside to close. Same fields and actions; "↗" opens the task in its project.

What opens it

  • Task title in Up next or Due today & overdue.
  • ▶ still starts focus right away, without opening anything.
  • Now card: the ring and the task name open Focus.

What it does

  • Status, priority, due change in place; Today refreshes behind it.
  • Done / Skip close the task and the panel; Undo shows briefly.
  • Focus starts the timer on it and keeps you on Today.
  • Open in project ↗ switches to that project's Tasks with this task open.

Later, same panel

  • Test cases (steps, pass/fail) and meetings (agenda, notes).
  • Reused by the Tasks page instead of its own popup.
