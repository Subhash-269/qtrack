What changes

  • Global views (Today, Focus) are separated from per-project views
  • The project list moves into a switcher with search and recent projects
  • Each project gets a color, auto-assigned and changeable
  • The timer sits on Focus instead of in a separate card

Safety

  • No always-visible ✕: archive and delete sit behind ⋯
  • Delete names what's lost, needs the project name typed, and offers Archive instead
  • Archived projects stay one click away in the switcher

Stays the same

  • All existing views, counts and the show/hide-views setting
  • Double-click to rename still works, and is also in ⋯
  • Phone bottom tabs; workshop projects keep their own view list
  • Only new data: a color per project (one column)
